# Minecraft DS

Minecraft DS is a Minecraft-inspired homebrew project for the Nintendo DS.

## Features

### 🌍 World

* Playable area consisting of **4 chunks**
* Each chunk is **14 × 14 blocks**
* Maximum world height of **20 blocks**

### 🎮 Controls

| Button            | Action                                                   |
| ----------------- | -------------------------------------------------------- |
| **D-Pad**         | Move the player                                          |
| **A / B / X / Y** | Control the camera                                       |
| **START**         | Reset the map and teleport the player back to the ground |
| **SELECT**        | Exit the game                                            |
| **R**             | Place a block                                            |
| **L**             | Activate Special Mode                                    |
| **L + B**         | Jump                                                     |
| **L + R**         | Break a block                                            |
| **L + A / Y**     | Change the selected block                                |

### ✨ Special Mode

Holding **L** activates the **Special Mode**, allowing additional actions to be performed by combining it with other buttons:

* **L + B** → Jump
* **L + R** → Break the targeted block
* **L + A / Y** → Change the block selected for placement

### 🧱 Blocks

There are currently **8 block types** available:

* Dirt
* Stone
* Cobblestone
* Bedrock
* Moss
* Glass
* Planks
* Diamond Ore

### 📊 HUD

The bottom screen displays useful gameplay information:

* Player position
* Selected block ID
* Play time
* FPS

### 🎵 Music

The music currently played at startup is **Wet Hands**, an original Minecraft track composed by **C418**.
